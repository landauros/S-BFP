# Licensing decision required

The original repository contains no license. A public archive is not practically
reusable until the rights holders add explicit terms.

Recommended split for author review:

- source code: Apache License 2.0 or MIT License;
- documentation: the same code license or Creative Commons Attribution 4.0;
- de-identified aggregate dataset: Creative Commons Attribution 4.0.

Do not copy license text into the repository until all rights holders agree and
the paper's disclosure/anonymity phase permits attribution. After selection:

1. add the complete license text as `LICENSE`;
2. add any separate dataset terms under `data/public/LICENSE`;
3. record third-party notices if additional dependencies or assets are added;
4. add author/citation metadata to `CITATION.cff` for the camera-ready release.
